Humanoid-RS

A memory-safe, real-time robotics framework for humanoid robots built in Rust. Control robots with confidence using modern tools and safety guarantees.

Get Started API Reference
🦀

Memory Safe

Built with Rust's ownership system to eliminate memory bugs and data races at compile time. Perfect for safety-critical robotics applications.

⚡

Real-Time Control

Deterministic control loops running at 500-1000 Hz with low jitter. Pre-allocated memory and lock-free data structures.

🎮

3D Simulator

Built-in simulator using Bevy and Rapier3D for rapid prototyping. Test algorithms before deploying to real hardware.

🔧

Hardware Support

Ready-to-use drivers for Unitree G1 humanoid robot. ROS2 bridge for integration with existing robotics stacks.

🧠

Advanced Control

MPC for locomotion, whole-body control for coordination, inverse kinematics, and balance recovery algorithms.

📊

Observable

Comprehensive sensor integration with IMU, joint encoders, and force sensors. Built-in logging and monitoring capabilities.

Quick Example

use humanoid_rs::sdk::prelude::*;
use std::time::Duration;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Create SDK and connect to simulator
    let mut sdk = HumanoidSDK::new();
    let _sim = sdk.connect_simulator(SimulationConfig::default())?;
    
    // Connect to robot
    let robot = sdk.connect_robot(RobotProfile::unitree_g1())?;
    
    // Command robot to stand
    robot.stand_up()?;
    
    // Run for 5 seconds
    std::thread::sleep(Duration::from_secs(5));
    
    sdk.shutdown();
    Ok(())
}
