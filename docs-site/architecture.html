Architecture

System architecture, data flow, and component interactions.

Overview

Humanoid-RS is a memory-safe, real-time robotics framework built in Rust.

System Architecture

Application Layer
  └── LLM Agent, Motion Planner, Teleop
       │
       ▼
Humanoid-RS Framework
  ├── Robot API Layer
  │   └── HumanoidRobot trait
  ├── Control Layer
  │   ├── Motion Planner
  │   ├── Joint Controller
  │   ├── MPC Controller
  │   └── Whole-Body Control
  └── Hardware Layer
      ├── Unitree Robot
      ├── ROS2 Bridge
      └── Simulator (Bevy)
